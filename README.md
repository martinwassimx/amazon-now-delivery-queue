# نظام طابور التوصيل الذكي بكود QR — أمازون ناو مصر
## Amazon Now QR-Based Delivery Queue Management System (Egyptian Arabic & Mobile-First)

نظام إدارة طابور تسليم شحنات متكامل وفوري لمندوبي وسائقي التوصيل في محطات التوزيع بمصر، مبني بالكامل بلهجة **العامية المصرية** الطبيعية وواجهة **RTL** كاملة ومتوافقة تماماً مع أجهزة الموبايل والشاشات الكبيرة.

---

## 🌟 الفكرة الرئيسية وسير العمل (Workflow)

1. **كود QR دائم**: في كل محطة توزيع، يوجد كود QR واحد ثابت ودائم معلق عند مدخل ساحة الاستلام.
2. **بدون تسجيل وبدون تعقيد**: يمسح السائق كود الـ QR بكاميرا موبايله فتفتح له صفحة بسيطة بزر ضخم **"ادخل الطابور"**.
3. **تخصيص تسلسلي متزامن وآمن (Atomic Allocation)**: بمجرد الضغط، يخصص خادم قاعدة البيانات رقماً تسلسلياً فريداً فوراً دون أي احتمال لتكرار الأرقام أو تصادم الطلبات المتزامنة.
4. **تذكرة رقمية فورية**: يرى السائق رقمه بالبنط العريض، ترتيبه في الطابور، وعدد السائقين قبله، مع تقدير وقت الانتظار.
5. **تنبيهات حية وصوتية (Realtime & Chime)**:
   - عندما يضغط موظف المحطة على **"نده على اللي بعده"**، يرن هاتف السائق ويهتز فوراً، وتتحول تذكرته للون الأزرق مع رسالة واضحة: **"دورك جه! اتفضل استلم طلبك."**
   - يظهر رقم السائق فوراً على شاشة العرض التلفزيونية في صالة الانتظار.
6. **إنهاء الطلب والزيارات المتكررة**:
   - عند تسليم الشحنة، يضغط الموظف **"تم استلام الطلب"**.
   - يُزال الدور من الطابور النشط، وتتحول شاشة السائق إلى: **"تم استلام الطلب بنجاح. لو عندك طلب جديد، امسح الـ QR تاني وادخل الطابور من جديد."**
   - يمكن لنفس السائق الدخول فوراً في طابور جديد لشحنة أخرى بضغطة زر.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework**: Next.js 16 (App Router, Server & Client Components)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS v4 مع نظام ألوان داكن أنيق (Dark Navy, Electric Blue, Amazon Amber, Emerald)
- **Typography**: خط القاهرة العربي الأصيل (`Cairo` Google Font) مع دعم اتجاه اليمين لليسار (`dir="rtl"`)
- **Database & Realtime**: Supabase PostgreSQL مع Stored Procedures، Row Level Security (RLS)، و Supabase Realtime
- **Client Feedback**: Web Audio API (توليد نغمات تنبيه ديناميكية ثنائية النغمة بدون ملفات صوت خارجية) + Vibration API + Canvas Confetti
- **QR Generation**: مكتبة QR مع مولد بوسترات جاهزة للطباعة بجودة A4 وSVG/PNG
- **Testing**: جناح اختبارات متكامل مبني بـ `tsx` يفحص 14 سيناريو وتزامناً حرجاً

## 📱 صفحات وواجهات النظام

1. **صفحة السائق الرئيسية (`/`)**:
   - متوافقة مع شاشات الهواتف ابتداءً من 320px
   - زر ضخم عالي التباين **"ادخل الطابور"** بارتفاع أكثر من 56px يسهل الضغط عليه بيد واحدة
   - حماية كاملة من الضغط المزدوج (Idempotency Key)
   - حقول اختيارية لرقم الشحنة أو اسم المندوب

2. **تذكرة السائق الخاصة (`/ticket/[token]`)**:
   - رابط خاص برمز تشفير غير قابل للتخمين (48-char secure token)
   - رقم الدور بحجم ضخم (مثال: `0042`)
   - ترتيب الدور وعدد المنتظرين قبله
   - تحديث لحظي عبر Realtime وبديل دوري تلقائي
   - نغمة تنبيه واهتزاز فور النداء

3. **لوحة تحكم موظفي المحطة (`/staff`)**:
   - بطاقات إحصائيات حية: (عدد اللي مستنيين، الطلبات اللي اتنده عليها، جاري تجهيزها، خلصت النهارده)
   - زر سريع للنداء: **"نده على اللي بعده"**
   - جدول وكروت أدوار حية مع أزرار الإجراءات:
     - **"نده على السائق"** / **"نده عليه تاني"**
     - **"ابدأ تجهيز الطلب"**
     - **"تم استلام الطلب"**
     - **"تخطي الدور"** و **"إلغاء الدور"** مع نوافذ تأكيد لمنع الأخطاء

4. **سجل الطلبات السابقة (`/staff/history`)**:
   - عرض كافة الطلبات المنتهية والمستلمة اليوم مع التوقيت بتوقيت القاهرة (`Africa/Cairo`) ومحرك بحث سريع.

5. **سجل الرقابة والعمليات (`/staff/audit`)**:
   - تسجيل فوري لأي إجراء يتخذه موظف (من نادى، من جهز، من سلم، من ألغى) بالوقت والتفاصيل.

6. **إدارة كود الـ QR وبوستر المحطة (`/staff/qr`)**:
   - عرض كود الـ QR الدائم للمحطة
   - زر تحميل كود الـ QR بصيغة PNG عالية الدقة
   - بوستر مطبوع احترافي جاهز للتعليق مقاس A4 يتضمن تعليمات واضحة للمندوبين بالعامية المصرية.

7. **شاشة العرض العامة للتلفزيون (`/display`)**:
   - مخصصة لشاشات العرض التلفزيونية في صالة انتظار المحطة
   - تعرض **"الدور الحالي"** بخط ضخم متوهج ورقم الشحنة
   - قسم **"جاري تجهيز الطلب"** وقسم **"الأدوار اللي جاية"**
   - زر ملء الشاشة (Fullscreen) ونغمات تنبيه صوتية عند استدعاء أي دور جديد

8. **تسجيل دخول الموظفين (`/staff/login`)**:
   - دعم Supabase Auth بالبريد وكلمة المرور
   - زر دخول تجريبي بضغطة واحدة للمعاينة والتطوير المحلي السريع

## 🗄️ قاعدة بيانات Supabase والهجرة (Database Schema)

ملف الهجرة الكامل موجود في [`supabase/migrations/20261011_initial_schema.sql`](file:///c:/Users/msfir/OneDrive/Desktop/Github%20Project/amazon-now-delivery-queue/supabase/migrations/20261011_initial_schema.sql).

### الجداول الأساسية:
- `sites`: مواقع ومحطات التوزيع (محطة القاهرة، إلخ).
- `queue_sessions`: الجلسات اليومية والعداد التسلسلي التراكمي.
- `queue_entries`: تذاكر وأدوار الطابور مع الحالات (`waiting`, `called`, `processing`, `completed`, `skipped`, `cancelled`).
- `staff_profiles`: حسابات وصلاحيات الموظفين.
- `audit_logs`: سجل العمليات والرقابة.

### الدوال المخزنة المتزامنة (Stored Procedures):
- `join_queue_atomic`: تستخدم قفل السطر `FOR UPDATE` على الجلسة اليومية لضمان تسلسل الأرقام بدون أي تكرار تحت ضغط الطلبات المتزامنة، وتتحقق من `idempotency_key`.
- `call_next_driver`: تستخدم `FOR UPDATE SKIP LOCKED` لاختيار أقدم سائق في الانتظار بنظام FIFO.
- `update_queue_entry_status`: تعالج الانتقال بين الحالات وتسجل العملية في سجل الرقابة تلقائياً.

## 🚀 التشغيل المحلي (Local Development)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد ملف البيئة:
أنشئ ملف `.env.local` بناءً على `.env.example`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```
*(ملاحظة: النظام مزود بنظام محاكاة داخلي ذكي يعمل فوراً بدون مفاتيح في بيئة التطوير، ويتصل بـ Supabase تلقائياً بمجرد إدخال المفاتيح).*

### 3. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).

### 4. تشغيل الاختبارات الآلية (Automated Tests):
```bash
npm test
```
يقوم هذا الأمر بتشغيل جناح الاختبارات الشامل في `tests/queue-workflow.test.ts` والتحقق من التزامن وحماية التكرار ودورة حياة الطلب.

### 5. بناء نسخة الإنتاج (Production Build):
```bash
npm run build
```

## ☁️ النشر على Vercel (Vercel Deployment)

1. ارفع الكود إلى مستودع GitHub الخاص بك:
   ```bash
   git add .
   git commit -m "feat: complete delivery queue system in Egyptian Arabic"
   git push origin main
   ```
2. اربط المستودع في منصة [Vercel](https://vercel.com).
3. أضف متغيرات البيئة من ملف `.env.example` في إعدادات مشروع Vercel (`Environment Variables`):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `NEXT_PUBLIC_SITE_URL` (رابط الدومين الخاص بك على Vercel)
4. اضغط **Deploy**. التطبيق متوافق وجاهز فوراً للعمل على بيئة Vercel Edge & Serverless Functions.
